apps/ -- host- and board-side software for the taoFPGA accelerator
=================================================================

Bare-metal Zynq PS self-test (C++)
----------------------------------
  main.cpp      Entry point: build random int8 A, B; C = A*B on the CPU;
               C_hard = A*B on the FPGA; compare; print Right!/Wrong!.
  Matrix.h/.cpp Padded fixed-point matrix container, the CPU reference
               matmul (Matrix_mul_soft), and the FPGA driver
               (Matrix_mul_hard: control-register + triple-AXI-DMA
               sequence).
  Defines.h    Address map (accelerator control regs + the 3 AXI-DMA
               channels) and sizing constants. A_SIZE must match the RTL.
  lscript.ld   Linker script (generated by the Xilinx SDK linker-script
               generator; regenerate from the BSP, do not hand-edit).
  Xilinx.spec  gcc spec file pulled in by the SDK toolchain.

  Build as a Vitis / Xilinx SDK "Application Project" against a BSP for the
  platform exported in exports/ (design.xsa). It needs the standalone BSP
  headers (xparameters.h, xil_io.h, xil_cache.h, xaxidma_hw.h, ...).

PYNQ / Jupyter driver (Python)
------------------------------
  MM.py          TransformerAccelerator class: same matmul-plus-softmax-plus-
                GELU pipeline driven from PYNQ over an Overlay built from
                exports/design.bit + design.hwh. Register offsets follow
                sourcecode/top/transformer_block_axi.v's documented map.
  golden_model.py  Pure-Python bit-faithful reference for the
                MM_ultra -> Softmax_control -> EightGelus pipeline; mirrors
                the SystemVerilog reference tasks in
                sourcecode/tb/transformer_block_tb.sv.

Vision Transformer kernel benchmark (Python)
--------------------------------------------
  vit/vit_numpy.py         Pure-NumPy ViT-Tiny forward pass (runs on the
                          board's 32-bit ARM, which has no PyTorch).
  vit/export_vit_weights.py  Dev-machine-only: fetch pretrained timm
                          weights + reference logits as plain .npy/.npz.
  vit/vit_benchmark.py     End-to-end kernel speedup measurement
                          (accelerator vs. NumPy), both attention shapes.
  vit/assets/              Sample image + ImageNet class list (see NOTICE);
                          the large weight files are gitignored and
                          regenerated by export_vit_weights.py.
